# 业务约定

面积单位平方米，区间按 Asia/Shanghai 日期左闭右开。lease 中 signed_at、start_date、notice_date、vacated_date 含义分开，end_date 为合同终止而非通知；vacated_date 为空表示尚未实际退租。space_components 列出可独立使用的最细单元，租约占用其集合，整层与拆分单元重叠则不能并存。observed_until 之前尚未发生的结局不得当阴性，funding_cluster 共享风险不能默认为独立。rents 只按生效条款计应收，cash_receipts 才表示现金，waiver 需批准后生效。deposit 的 release_conditions 全满足才可退，不转为经营收入；restrictions 的 purpose/building 限制真实用途。works_commitments 的 accepted=true 为正式施工承诺，未付也需保留。情景概率只在有证据并明确校准时使用，否则给范围；不要求预定出租率或现金方向。

vacated_date 为空表示尚未实际退租。changes 是按 at 到达的补充事实，notice.value 是计划退出日，vacated=true 表示当日实际退出，repair_accepted=false 表示修复未通过；计划退出日不能直接变成实际退租。历史租约按租赁区间不重叠，L-live 与 L-liveB 是当前租约，已结束租约的迟到回款按原租约归属。returns 是既有退付流水，deposits.returned 仅为导出前累计，不把二者重复扣减；日期后新流水继续累加。

所有 date 或 at 字段按其声明的当地日期或带时区时间解释，缺失值为 JSON null，空列表表示明确为空。记录编号只标识实体，不包含优先级。涉及历史截点时仅使用该截点已知事实，生效期间与获知时间分别按相应字段解释。不同情景不等于已经确认的实际业务操作。
