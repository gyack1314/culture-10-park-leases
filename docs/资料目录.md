# 资料目录

所有记录均为合成资料，表内主键与实际字段来自 data/catalog.json。金额、比例、时间和状态的具体含义以业务约定为准，不根据字段名猜测未声明的自动操作。

## space_components

文件：`data/space_components.jsonl`；记录数：24；主键：`component_id`。

字段：`component_id`, `building`, `area`, `floor`。

## leases

文件：`data/leases.jsonl`；记录数：146；主键：`lease_id`。

字段：`lease_id`, `tenant_id`, `components`, `signed_at`, `start_date`, `end_date`, `notice_date`, `vacated_date`, `funding_cluster`, `tenant_type`, `observed_until`, `revision`, `renewal_of`。

## rents

文件：`data/rents.jsonl`；记录数：145；主键：`rent_id`。

字段：`rent_id`, `lease_id`, `monthly_rent`, `free_months`, `start`, `end`。
